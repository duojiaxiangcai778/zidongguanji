# 2026-11-27 液态玻璃界面重做（v4.1.0）

## 起因

用户看过 v4.0.2 说「液态玻璃可以重做一下」。先按规则包（`<harness>\plugins\ui-liquid-glass\docs\UI-RULES.md`）
逐条对照旧版 `web/style.css`，发现四个明确的反模式：

| 旧版做法 | 规则条款 | 问题 |
|---|---|---|
| `.ambient` 里三颗 `blur(64px)` + `float` 动画的径向渐变球 | 反模式「渐变球、装饰几何」 | 廉价，且是纯装饰 |
| `.card` 自己带 `backdrop-filter: blur(26px)`，4 张卡片各一层 | 「只允许一层 backdrop-filter」 | 多层模糊叠加发灰、掉帧 |
| 主色 `#6ee7ff` → `#a78bfa`（青→紫渐变）当强调色 | 反模式「荧光色、紫蓝渐变当主色」 | 不是从壁纸取的色 |
| 字号 10 / 10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 14.5 / 19 / 33 十级 | 「2–3 级字号」「别出现五级」 | 完全是随手写死的 |

另外 `.numfield .cap`、`.clockcap` 用了「小号 + 字距」，也在反模式清单里。

## 重做做法

### 材质：真正的一层玻璃

旧的四张卡片各带 blur，等于四层。新版改成：

- `.backdrop`：底层，壁纸原图，`scale(1.03)` 防边缘露白，**保持清晰**
- `.sheet`：**全窗口唯一一层** `backdrop-filter: blur(38px) saturate(150%)`，
  inset 7px，`border-radius: 18px`，吃的是下面那张壁纸
- `.card` / `.op` / `.chip` 等内层：**一律不再模糊**，只用「填充色 + 1px 高光边」做层次

玻璃浮在壁纸上，边缘 7px 能直接看到未模糊的壁纸，中部透过玻璃看到模糊后的壁纸 —— 这才是玻璃。

### 高光：画出来，不堆投影

- 顶边 1px：`linear-gradient(90deg, transparent, rgba(255,255,255,.34), transparent)`
- 左上角镜面：`radial-gradient(120% 90% at 6% -30%, rgba(255,255,255,.26), transparent 55%)`
- 内层卡片的顶高光单独一条 `.card::before`，不靠 `box-shadow` 堆

### 取色：真的从壁纸采样

新增 `web/glass.js`：
- 壁纸画到 40×24 canvas 采样
- 平均色 → 保色相、S 封顶 0.12、L 压到 0.13 → 玻璃底色 `--glass-tint`
- 饱和度最高的中高明度像素 → 强调色种子，再钳制 **S∈[0.30,0.50]、L≈0.70**（深色底）
- 同时算出强调色上的文字色 `--accent-ink`（同色相 L 0.14，保证对比度）
- 壁纸本身就灰（最高饱和度 < 0.08）时不硬造强调色，退回 CSS 兜底

后端新增 `/backdrop.jpg` 路由（`app.py` 的 `do_GET`）：

```python
if path == "/backdrop.jpg":
    data, ctype = read_wallpaper_bytes()
```

为什么不复制到 `web/`：打包后 `WEB_DIR` 在 `_MEIPASS` 临时目录，每次启动复制一张 4K 壁纸既慢又白写；
前端也不能直接读 `file://`（http 页面混 file 源会被 WebView2 拦）。壁纸超过 12MB 就不给，
并用 mtime 缓存避免重复读盘。

### 排版：收敛到三级

- `--fs-display: 34px`（只有时钟）
- `--fs-body: 13.5px`
- `--fs-note: 11.5px`

删掉所有 `letter-spacing`，删掉 `.clockcap` 的字距。数字统一 `tabular-nums`。

### 图标：Unicode 字形 → 线条 SVG

旧的 8 个操作图标是 `⏻ ↻ ⎋ ☾ ▣ ▶ ♪ ✦`（字形当图标，尺寸和线宽都不可控）。
换成 24×24 viewBox、`stroke-width: 1.6`、`stroke-linecap: round` 的线条图标，
颜色走 `currentColor`，选中态自动变成 `--accent-ink`。

### 动效

统一 `--dur: 180ms` + `--ease: cubic-bezier(.2,.7,.25,1)`，只动 `transform / background / border-color / opacity`；
hover 抬 1px，按下 `scale(.985)`，禁用 38%。`prefers-reduced-motion` 降到 1ms。

## 验证

在真实环境、真实壁纸下跑（源码启动，不是干净环境）：

- `v4.1.0` 启动，日志 `前端已连接，返回初始化数据（v4.1.0）`
- 截图确认：玻璃边缘能看到未模糊壁纸、中部透出模糊壁纸、强调色由壁纸决定（本次采样出淡蓝紫）
- 8 个 SVG 图标逐个核对，互不相同（用正则取每条的 `path d` 首段比对）
- 三级字号在 1092×663 窗口下无挤压、无溢出

**踩过的坑**：给 8 个图标做批量替换时，第一版正则 `ico: '[^']*'` 没收敛到 key，
把 8 个全替换成了同一个图标；发现后用 `git checkout -- web/app.js` 还原，
改成按行、按 key 精确替换，再逐条校验 `path d` 互不相同。
