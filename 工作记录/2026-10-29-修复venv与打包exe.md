## 三、打包 exe

```powershell

  --name "定时关机" --paths . --distpath dist --workpath build --specpath build gui.py
```

产物：`dist\定时关机.exe` **11.13 MB**，复制到项目根。

**保留旧的 `自动关机工具.exe` 并另存 `自动关机工具-cli.exe`** ——
这是 DSH 会话里免审批的 CLI 关机通道（`自动关机工具.exe X /t=N`），不能被新 GUI 覆盖掉。

## 四、exe 验证踩的坑

启动后 `Get-Process 定时关机` 显示 `MainWindowHandle = 0`、`MainWindowTitle = 空`，一度以为打包失败。

**真相**：PyInstaller `--onefile` 是**两段进程** ——
先起一个引导进程（无窗口），解压到临时目录后再起真正的应用进程（有窗口），两者**进程名相同**。

`Get-Process | Select -First 1` 拿到的是引导进程，所以看不到窗口。

正确查法：

```powershell
Get-Process | Where-Object { $_.MainWindowHandle -ne 0 -and $_.MainWindowTitle -ne '' }
```

实测：`PID 8632  进程名 定时关机  标题 定时关机` —— exe 正常。
