## 二、旧版问题定位

| 现象 | 根因 |
|---|---|
| 卡 | 用 `customtkinter`（每个控件是 Canvas，重绘开销大）+ `ui/main_window.py` 单文件 **48KB** |
| 输入消失 | 定时刷新循环里动了 Entry（重建控件 / 重新 set 文本），用户正在输入的内容被覆盖 |
| 快捷方式跑错程序 | `定时关机.lnk` → `E:\【工具】\PShutDown ...\PShutdown.exe` |

## 三、新实现：`gui.py`（24KB 单文件）

### 设计决策

1. **不用 customtkinter**，回到 tkinter 原生 + 轻量自绘：
   - 卡片 = `Frame` + `highlightbackground` 细边框（比 Canvas 圆角省一个数量级）
   - 分段按钮 = `Label` + 背景色切换
   - 操作行 = `Frame` + 左侧 4px 色条，选中态换底色（比 Radiobutton 在深色下好看）
2. **输入框永不被程序写入**：
   - 全部绑 `StringVar`，只有用户输入和「浏览」按钮会写
   - `_tick()` 每 500ms **只更新倒计时那一个 Label**，绝不 touch Entry
3. **单列垂直布局**：两栏在 1000px 窗口下反复横向溢出，改单列后彻底消除
4. **主按钮放顶部**：底部按钮在内容超长时会被挤出可视区，移到倒计时下方永远不会丢

### 保留并复用

- `core/timer_engine.py`：三种定时模式（倒计时 / 指定时间 / 每周循环）
- `core/actions.py`：8 种操作（关机 / 重启 / 注销 / 睡眠 / 关屏 / 运行程序 / 播放声音 / 弹消息）
- `core/config.py`：记忆上次选择（模式 / 操作 / 星期）

## 六、踩的坑

1. **`.venv` 是废的**：`pyvenv.cfg` 的 home 指向已删除的 HermesDesktop 便携运行时，
   直接调用 `.venv\Scripts\python.exe` 报 `No Python at '...python.exe'`。
2. **`pyw.exe` ≠ `pythonw.exe`**：bat 里写 `start /b pythonw` 时被解析成了 Python Launcher（`pyw`），
   启动出来只有一句 `Python Launcher is sorry to say ...`。改用 `pyw -3.11` 显式指定版本。
3. **`.bat` 必须 CRLF + ASCII**（老坑复现）：LF 会让 cmd 把相邻行拼一起解析。
4. **tkinter 布局溢出**：两栏 + 2 列网格在 1000px 窗口下内容宽于窗口，右侧被裁；
   `pack(side="bottom")` 的底部按钮在内容超长时被挤出。最终改单列 + 按钮置顶解决。
5. **状态条与倒计时重叠**：两者都 `grid(row=0)` 互相覆盖，重排行号后正常。
