# 自动关机工具

基于 Python + tkinter 复刻 PShutDown v1.2.3 的功能，提供图形界面和命令行两种使用方式。

## 功能

### 可执行操作（8 种）

| 操作 | CLI 参数 | 说明 |
|------|----------|------|
| 关闭电脑 | `X` 或 `S` | 立即或定时关机 |
| 重启电脑 | `R` | 立即或定时重启 |
| 注销电脑 | `L` | 立即或定时注销 |
| 进入睡眠模式 | `/sm` | 立即或定时睡眠 |
| 关闭显示器 | `/som` | 立即或定时关屏 |
| 运行程序 | `/rp=路径` | 定时启动程序 |
| 播放声音 | `/ra=路径` | 定时播放音频 |
| 弹出消息提示框 | `/m=文本` | 定时弹出通知 |

### 定时模式（3 种）

- **倒计时模式** — 设定秒/分/时/天后执行
- **日期定时** — 指定具体日期时间执行
- **周期循环** — 每周指定日期的指定时间循环执行

### CLI 命令行参数

```
自动关机工具.exe <操作> [/t=秒] [/w] [/min]
```

| 参数 | 说明 |
|------|------|
| `X` / `S` | 关闭电脑 |
| `R` | 重启电脑 |
| `L` | 注销电脑 |
| `/sm` | 进入睡眠模式 |
| `/som` | 关闭显示器 |
| `/rp=路径` | 运行指定程序 |
| `/ra=路径` | 播放指定声音文件 |
| `/m=文本` | 弹出消息提示框显示文本 |
| `/t=秒` | 以秒为单位设置倒计时 |
| `/w` | 不要自动开启倒计时（需配合 /t 使用） |
| `/min` | 启动后最小化到系统托盘 |

## 使用方式

### 图形界面

双击 `启动GUI.bat`

### 命令行

```
# 5 秒后关闭电脑
python main.py X /t=5

# 30 秒后重启（不自动开始倒计时）
python main.py R /t=30 /w

# 立即关显示器
python main.py /som

# 弹出消息框
python main.py /m=你好世界

# 20 秒后运行记事本
python main.py /rp=C:\Windows\notepad.exe /t=20
```

## 目录结构

```
E:\自动关机工具\
├── main.py                    # 入口 + CLI 参数解析
├── core/
│   ├── actions.py             # 8 种操作的实现
│   ├── config.py              # settings.ini 配置管理
│   └── timer_engine.py        # 倒计时引擎（3 种模式）
├── ui/
│   └── main_window.py         # Tkinter GUI 主窗口
├── 启动GUI.bat                 # GUI 启动快捷脚本
├── CLI测试.bat                 # CLI 测试快捷脚本
└── settings.ini               # 配置文件
```

## 技术栈

- Python 3.11
- tkinter（GUI 界面）
- ctypes（系统托盘、Windows API 调用）
- subprocess/os（执行系统操作）

## 注意事项

- 关机/重启/注销等操作执行前会弹出确认窗口（可在设置中关闭）
- 默认配置下，关闭程序时会有确认提示
- Windows 专属（使用了 Windows API）
